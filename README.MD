# Tópicos de Big Data

Repositorio de prácticas y proyectos desarrollados durante la materia de
*Tópicos de Big Data*. Cada unidad organiza sus datos, notebooks, código y
dependencias de forma independiente.

## Estructura

```text
├── U1_1_probabilidad_estadistica/
├── U2_1_modelos/
├── U4_1_clustering/
├── examen1parcial/
└── examen2parcial/
```

Cada unidad contiene su propio `README.md` y `requirements.txt`. Los archivos
grandes o los datasets que no están versionados se describen en la
documentación del proyecto correspondiente.

## Segundo examen parcial

El dataset `nyc_taxi_examen.csv` no está incluido por su tamaño. Para ejecutar
el notebook, coloca el archivo en `examen2parcial/data/raw/`; esta ruta está
excluida de Git mediante el `.gitignore` del examen.
