# U1.1 Probabilidad y Estadística

Proyecto de la materia de Big Data — Unidad 1.1: Probabilidad y Estadística.

## Estructura del proyecto

- `data/raw/` — Datos originales, sin modificar.
- `data/processed/` — Datos ya transformados/limpios.
- `notebooks/` — Jupyter Notebooks del análisis.
- `src/` — Código Python reutilizable (funciones, módulos).
- `requirements.txt` — Dependencias del proyecto.
- `.venv/` — Entorno virtual local (no se sube a GitHub).

## Cómo usar

1. Crear entorno virtual: `python -m venv .venv`
2. Activarlo: `.venv\Scripts\activate` (Windows) o `source .venv/bin/activate` (Mac/Linux)
3. Instalar dependencias: `pip install -r requirements.txt`
4. Abrir el notebook en `notebooks/01_probabilidad_estadistica.ipynb`

## Actividades

Los notebooks de esta unidad incluyen probabilidad y estadística,
transformaciones, NumPy, evolución poblacional y fertility rate. Los notebooks
de modelos y clustering, junto con sus datasets, están organizados en
`U2_1_modelos/` y `U4_1_clustering/`, respectivamente.
